# 结算请示报告 · 统一模板说明

> 模板文件：`templates/结算请示模板.docx`
> 体例来源：《关于阳101H51平台电撬压裂施工技术服务结算的请示》（2026-09）
> 占位符统一用「〔…〕」标注，填写时整体替换，保留两侧方括号去掉。

## 一、固定要素（不随项目变动）

- 左上角密级：一般商密
- 红头：请示（红色，方正小标宋简体，31pt）；右下：技服子公司
- 签发人：留空
- 称谓：尊敬的公司领导：
- 一级标题：一、供应商信息及结算明细；二、申请事项
- 结束语：妥否，呈请领导批示。
- 落款单位：技服子公司；版记：技服子公司 ｜ 印发日期印

## 二、占位符清单（每次填写替换）

| 占位符 | 含义 | 示例 |
|---|---|---|
| 〔项目/平台〕 | 项目或平台名称 | 阳101H51平台 |
| 〔服务类型〕 | 施工/服务类别 | 电撬压裂施工技术服务 |
| 〔YYYY年MM月DD日〕 | 起止日期、落款日期、印发日期 | 2026年4月16日 |
| 〔井号清单〕 | 本次涉及的全部井号 | 阳101H51-1、2、3井 |
| 〔供应商家数〕 | 下游供应商数量 | 一（家） |
| 〔供应商全称〕 | 营业执照全称 | 阿奥艾斯石油工程服务成都有限公司 |
| 〔供应商简称〕 | 正文/附件中使用的简称 | 阿奥艾斯 |
| 〔13%/9%〕 | 税率，按各项目合同约定二选一 | 13% |
| 〔含税总价（元）〕 | 合同含税总价，千分位两位小数 | 4,893,490.26 |
| 〔本次结算金额（元）〕 | 本次申请结算金额，千分位两位小数 | 3,425,443.18 |
| 〔结算比例〕 | 本次暂结工作量比例 | 70 |
| 〔井号〕 | 附件工作量确认单对应的单井 | 阳101H51平台1井 |

## 三、已确认的填写规则（2026-11-11）

1. **税率可切换**：表头税率按项目执行合同填 13% 或 9%，不在模板里写死。
2. **多供应商**：结算明细表一家供应商一行；超过一家时复制示例行续排，列宽与对齐不变。
3. **不写合同编号**：正文与附件均不列合同编号。
4. **不预留复杂情形段落**：前期挂账、红冲发票、抵账、部分已付等不在本请示模板内设段落。
5. **不设文号**：文件名不再沿用 QSZDYHS+日期+序号 编号规则。
6. **签发人留空**：每次发文前由签发人本人手签。
7. **附件三类必备，其余可追加**：
   - 必备：①合同 ②结算单 ③工作量确认单（逐井列）；
   - 其他材料（补充协议、签证、对账单等）按项目实际情况在清单末尾追加编号。

## 四、格式规范（沿用原稿）

- 正文：仿宋，16pt（sz32）；行距 240 atLeast
- 表格：仿宋_GB2312 / Times New Roman，14pt（sz28），居中；表头浅蓝底 B4C6E7
- 标题：22pt（sz44）
- 金额：千分位分隔，保留两位小数，单位元
- 页数：控制在两页内，落款与版记同页

## 五、生成方式

复制 `结算请示模板.docx` 一份，按上表替换占位符；多供应商时复制表格数据行；附件清单按实际增减行。
